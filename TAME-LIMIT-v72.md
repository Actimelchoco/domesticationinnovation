# Tame limit v72

100 qualifying tames total per player, across all types, replacing the old 10-per-type limit.
Only level 10+ tames with at least one ability or attribute upgrade count, as before.
Newest excess tames retain the ten minutes of owner-online grace time, wild release,
and lost-registry recovery. Existing grace timers reset on the next online accounting
pass for tames now within the allowance. No configuration changes required.

Stop the server and replace the previous Domestication Innovation extension JAR;
keep only one copy. Output is staged in Downloads/Mods.
