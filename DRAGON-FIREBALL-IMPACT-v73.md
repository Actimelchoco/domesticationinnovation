# Dragon fireball block impact v73

Tame dragon fireball splash, particles, sound and breath cloud now originate at
the actual collision point. Block impacts place the effect just outside the struck
face, rather than at the projectile position before movement. Removed projectiles
cannot trigger duplicate impacts. No block destruction or fire placement is added.

Includes v72: 100 qualifying tames total per owner, with existing exemptions,
online grace period and lost-registry recovery.

Replace the previous extension JAR while the server is stopped. No config changes.
